📖 接口文档

接口文档（/docs.json）为公开数据，无需管理令牌即可查看。

管理令牌用于概览 / Token 管理 / 登录管理等 /admin/* 页面。

🚀 快速上手

  1. 获取管理令牌：服务端启动日志会打印，或读取数据目录下的 admin-token 文件内容，粘贴到右上角「管理令牌」输入框后点「连接」。
  2. 创建 API Token：切换到「Token 管理」页，填写名称点「创建」，复制弹出的完整令牌。
  3. 管理接口鉴权头（/admin/*）：X-Admin-Token: <管理令牌>
  4. 业务接口鉴权头（/api/v1/*）：Authorization: Bearer <API Token>
  5. AUTH_MODE 说明：未连接时无法读取当前鉴权模式，连接后自动显示。

下方所有 curl 中的 <管理令牌> 均为占位符，请替换为你自己的值；点击路径可复制整条 curl。
